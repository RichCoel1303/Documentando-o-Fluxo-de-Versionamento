# Documentando o fluxo de versionamento

## 🗃️Como criar um repositório?🗃️
*Repositorio:* Para criar um repositório no GitHub é bem simples, vá no botão "create new" na parte superior da pagina, logo em seguida clique em "new repository", lá temos a opção de adicionar o nome e a descrição desejadas no repositorio, alem de poder adicionar o READ.ME onde colocamos uma espécie de apresentação do nosso projeto, gitignore para indicar quais partes do projeto não devem ser publicadas ou rastreadas, e claro a licença para declarar que o código é seu de direito impossibilitando o uso sem permissão, após finalizas as configurações é só clicar "Create repository", onde vai criar o local que tera nosso READ.ME e poderemos anexar arquivos vinculados a nosso projeto, como codigos e assets.

## 🛜CONEXÃO COM O REPOSITORIO🛜
*GitHub Desktop: * Para vincular uma pasta ao seu Github de forma local é bem simples, acesse o aplicativo Github - Desktop, na barra de menus acesse *Arquivo*, e logo em seguida clique em *Adicionar repositório local*, após isso selecione a pasta desejada que ela será vinculada ao repositorio que você escolher.
